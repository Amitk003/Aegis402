# Aegis402 Memory Pattern

This directory serves as the project's memory. It contains records of logs, ideas, research, and a roadmap.
When taking over or reviewing this project, start here to understand exactly how the project evolved.

## Directory Structure
- `logs/`: Contains step-by-step records of actions taken (e.g., commands run, dependencies installed).
- `idea/`: Stores the initial research, problem statements, and core ideas for Aegis402.
- `roadmap/`: Details the high-level roadmap and future plans.
- `memory.md`: This file, outlining the memory pattern.

## Memory Update Protocol
Engineers working on this project must:
1. Update `logs/` after significant actions or at the end of a work session.
2. Update `idea/` if new architectural decisions or research findings emerge.
3. Update `roadmap/` as features are completed or new features are planned.
